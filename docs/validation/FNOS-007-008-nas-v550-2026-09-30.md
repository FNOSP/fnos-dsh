- `[验收]` 侧边栏「新建终端」打开即可用：标签页显示单个 `bash`（无重复 bash、无 nologin），
  提示符 `fn-deepseek-harness@fnos-nas:/vol1/@appdata/fn-deepseek-harness$`。
- `[验收]` 终端内执行环境探针，实测输出：

  ```
  SHELL=/usr/bin/bash LANG=C.UTF-8 LC_CTYPE=C.UTF-8 LC_ALL= USER=fn-deepseek-harness
  HOME=/vol1/@appshare/fn-deepseek-harness
  ```

  即网关注入 UTF-8 `LANG`/`LC_CTYPE`、清除 `LC_ALL`、默认 Shell 解析为 PATH 中的 bash，
  运行身份为应用专用账号（非 root、非 NAS 普通用户）。
- `[验收]` `mkdir 测试中文目录` 成功且 `ls` 输出中文无乱码，`rmdir` 清理完成。终端可执行命令、可关闭。
