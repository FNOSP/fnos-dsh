# FNOS-045 应用与插件多语言 —— 真实 NAS 验收记录

## 环境与方法

- 环境：真实 fnOS NAS，**x86_64**。被测实现：`0a1de11 chore: release v7.1.0`（多语言特性本身在 `0eb924e0`）。
- 安装方式：应用中心正常安装（未走 SSH 改文件，未替换产物）。
- 方式：切换飞牛界面语言后，观察随包插件在 DSH 内的界面文案与语言切换；再切换系统语言后重新安装，观察安装向导的文案。

## 已通过用例

| 验收条件 | 验证结果 |
| --- | --- |
| `FNOS-045-04-AC-01`、`AC-03` | 通过。九种语言（中文、英文、日语、韩语、德语、法语、西班牙语、意大利语、俄语）逐个切换，插件文案均正确显示，切换即时生效，无需刷新页面。 |
| `FNOS-045-03-AC-01`、`AC-03` | 通过。**先设置系统语言、再安装应用**时，安装向导的步骤标题、字段标签与提示语随所选语言显示。 |
| `FNOS-045-05-AC-01`、`AC-02` | 通过。飞牛界面语言切换后，DSH 与插件界面语言随之切换。 |

## 一条容易踩空的操作前提

**语言必须在安装之前设置。** 向导文案在安装时取用；先装中文包再切语言，再打开向导看到的仍是安装那一刻的文案。这不是缺陷，是安装期取值的正常表现，但会让验证者误判为「i18n 没生效」。

首次验证时正是因为顺序相反（先装后切），一度以为向导只有标题被本地化、正文没有。按「先切语言 → 再安装」重做后，向导文案正确。

## 未覆盖的范围

- **应用中心的名称与描述**未逐语言确认：只验证了安装向导与 DSH 内部界面。这两处元数据走同一套 `i18n/` 机制，但没有独立的逐语言证据。
- **ARM64 设备**未验证：本记录来自 x86_64 设备，与 FNOS-044 的 ARM 验收无关。
- 未逐语言逐条抽查译文的措辞质量；此处只确认「显示与切换正确」。

## 结论

FNOS-045 的多语言显示、语言切换与 fnOS 语言联动在真实 fnOS NAS（x86_64）上通过。此前登记的两条保留风险据此关闭：

1. **语言文件名是推断的**（`ko-KR`、`de-DE`、`fr-FR`、`es-ES`、`it-IT`、`ru-RU`）——真机上九种均能正常识别并显示，说明平台按 BCP 47 接受这些文件名，不限于文档举例的三种。
2. **向导文案取值时机**——已确认，并记录为安装期取值。
