## 测试范围与需求分析

被测对象是插件对 HTTP 403 的分类与故障转移：除内容拦截（11128）与账号级受限（11140 + `request illegal`）外，其余 403 应触发换号并给出可见提示；401 与内容拦截语义不变。

### 关键风险点

| 风险 | 用例方向 |
| --- | --- |
| 内容拦截（可能以 403 出现）被误当成可换号，白耗其它账号额度 | 403 + 11128 必须仍为 `CONTENT_BLOCKED` |
| 账号受限（11140）被归进「其它 403」而丢失受限语义（不再写受限集合） | 403 + 11140 必须仍为 `ACCOUNT_RESTRICTED` |
| 401 被一并纳入换号，掩盖凭据失效 | 401 必须仍为 `AUTH` |
| 403 触发被「自动切换」偏好拦住 | 偏好关闭时仍应切换 |
| 提示原因与其它原因混用 | 断言 403 独立文案 |

## 测试环境

| 功能 | 执行环境 | 说明 |
| --- | --- | --- |
| FNOS-024-01 | 本地构测 + 适配器级集成验证 | 真实 403 无法按需构造，用本地桩让聊天端点返回 403（不带业务码），其余请求代理真实上游 |

被测插件不依赖 fnOS 专属能力，**不要求真实 NAS 验收**。
