# CodeBuddy

`@tnnevol/dsh-codebuddy` 可将腾讯 CodeBuddy 接入 DSH。登录通过浏览器授权完成，无需填写 API Key。插件提供多账号管理、额度查看和 Token 用量统计。

## 安装

在 fnOS 上使用 DSH 时，CodeBuddy 插件随应用安装或升级自动安装。其他 DSH 环境可在 Web profile 中安装：

```sh
dsh plugin --profile web add @tnnevol/dsh-codebuddy@0.1.7-rc.2
```

安装完成后重启 DSH Web profile。插件版本信息见[插件总览](/plugins/)。

## 添加账号

1. 在 DSH 左侧打开「插件」，进入 `@tnnevol/dsh-codebuddy` 插件详情页。
2. 在「账号管理」区域选择「添加账号」。
3. 按需填写备注名，选择登录客户端和对应环境；使用企业账号时按界面提示填写企业信息。
4. 点击「打开登录」，在浏览器中完成 CodeBuddy 授权。授权完成后，账号会出现在账号列表中。

![CodeBuddy 插件详情页的账号列表](</images/plugins/dsh-codebuddy/plugin-manager-account-list.jpg>)

添加账号时可选填写备注名，方便区分多个账号。再次添加已有账号会更新登录状态，不会重复创建账号；添加其他账号不会改变当前使用的账号。

![添加 CodeBuddy 账号对话框](</images/plugins/dsh-codebuddy/add-account-dialog.jpg>)

### 在 DSH Desktop 中登录

DSH Desktop 会在系统默认浏览器中打开授权页面。完成授权后返回 DSH，登录结果会自动更新。

## 管理账号

在插件详情页的「账号管理」区域可以查看已添加的账号及其额度状态。展开账号卡片或打开卡片菜单，可按需执行以下操作：

- **设为当前账号**：选择 DSH 当前用于 CodeBuddy 请求的账号。
- **修改备注名**：为账号设置便于识别的名称；清空备注名可恢复显示账号昵称。
- **重新登录**：账号掉线时重新完成浏览器授权。
- **删除账号**：从 DSH 中移除该账号。删除当前账号后，DSH 会改用其他可用账号；删除最后一个账号则需要重新登录。

账号卡片还会显示可用额度、资源包和到期时间。选择「刷新」可重新获取账号状态。某些账号类型不支持的功能不会显示。

## 使用模型

在 DSH 的模型选择器中选择 CodeBuddy 提供的模型即可使用，无需在插件面板另行添加模型。可用模型及其能力由服务提供方决定。

## 用量与偏好

输入框旁的用量指示器可查看剩余额度；悬停或点击可查看额度使用情况和重置时间。若未看到指示器，请确认已在偏好中开启「显示额度余量」，并且当前选择的是 CodeBuddy 模型。

在偏好设置或账号管理区域，可根据需要调整：

- **自动切换**：额度不足或请求被限流时，自动改用其他可用账号。
- **切换阈值**：设置自动切换使用的剩余额度比例；设为 0 可关闭按额度阈值主动切换。开启自动切换后，账号由插件自动选择，卡片中不显示手动切换入口。
- **自动签到**：开启后自动为支持此功能的账号签到。
- **自动旅行**：开启后自动处理账号支持的旅行任务。该功能是否可用取决于账号类型和服务支持。
- **显示额度余量**：控制输入框旁是否显示 CodeBuddy 用量指示器。

管理面板可从「管理面板」入口或输入区附近的管理图标打开。账号管理页可查看额度总览和资源包详情；「Token 统计」页可按时间范围查看 CodeBuddy 调用的 Token 用量、趋势及模型或工作区分布。统计范围可选近 7、30 或 90 天；数据取自本地 DSH 会话记录，不上传到 CodeBuddy。插件详情页里的「账号管理」与「Token 统计」是同级区块，标题常驻，进入即可看到内容。

## 常见问题

### 授权页面没有打开

在浏览器中允许 DSH 打开新标签页后重试。使用 DSH Desktop 时，授权页面会改由系统默认浏览器打开。

### 账号显示掉线

打开该账号的菜单，选择「重新登录」，并在浏览器中完成授权。

### 没有看到用量指示器

检查当前模型是否为 CodeBuddy 模型，并确认「显示额度余量」已开启。之后可在账号管理页选择「刷新」更新账号状态。

### 某些账号没有签到或旅行功能

功能是否显示取决于账号类型及服务支持；不支持的账号不会提供相应操作。
