## 需求背景

此前应用只在中文语境下可用：

- 应用包的 `desc`、`display_name`、`changelog` 与桌面入口标题都是中文硬编码，非中文用户在应用中心看到的是一段读不懂的说明。
- 安装、升级、配置、卸载四个向导表单同样是中文单语文本，非中文用户在安装第一步就卡住。
- 随包分发的 DSH 插件界面只有中文与英文，日韩德法等用户看到的是英文兜底。
- fnOS 的界面语言与 DSH 的界面语言互不相干：用户在飞牛里把语言切成日语后，DSH 仍然是原来的语言，需要再进设置手动改一次。

飞牛应用包支持 `i18n/` 目录，可为应用元数据、桌面入口和向导提供按语言分文件的可本地化文本；DSH 客户端支持由插件注册可选语言与对应文案字典；飞牛 JS SDK 提供当前界面语言与语言变化事件。三处能力各自存在，此前没有接起来。

## 需求目标

- 应用中心里，应用名称、描述与更新日志按用户当前界面语言显示。
- 桌面入口的标题与描述按界面语言显示。
- 安装、升级、配置、卸载向导的所有用户可见文本按界面语言显示。
- 随包的 DSH 插件界面提供中文、英文、日语、韩语、德语、法语、西班牙语、意大利语、俄语九种语言。
- fnOS 界面语言变化后，DSH 的界面语言随之切换，不需要用户再手动设置一次。

## 行为约束

- **各语言文件必须键集合一致**：应用包的每个语言文件包含相同的 section 与 key；插件每种语言的字典包含与中文语言相同的键。缺键会退化成英文兜底，但同一语言文件缺键属于缺陷，不算「翻译完成」。
- **技术标识不翻译**：应用 ID、入口 ID、字段名、URL、路径、端口、协议值、环境变量名、产品名（DeepSeek Harness、DSH、fnOS）在各语言中保持原样。
- **中文仍是权威来源**：现有中文文案是基准，其他语言按同一语义翻译，不新增或删除信息；中文改动需同步到其余语言。
- **DSH 本体界面不在本次范围**：DSH 上游只提供中文与英文两种界面语言。选择日韩德法等语言时，DSH 自身的界面文案回退英文，插件文案为目标语言。这是上游的能力边界，不是本应用的缺陷。
- **同步只在两种时机发生**：应用启动时按当前 fnOS 语言对齐一次，以及 fnOS 语言发生变化时。用户随后在 DSH 里手动选择的语言不会被持续覆盖——要恢复跟随，改飞牛语言或重启即可。本轮不提供单独的「关闭同步」开关：飞牛内嵌页面里 DSH 的语言来源就是飞牛语言，加开关会让「我的界面语言到底由谁决定」变成两个来源。
- **不改变既有安装行为**：本地化只影响展示文本，不改变向导收集的字段名、默认值、校验规则或环境变量，升级时既有配置保持不变。
- **缺少翻译时不得让界面不可用**：任何语言下界面都必须可操作；未翻译文本回退英文而不是显示占位符或空白。

## 不在本次范围内

- 不翻译 DSH 上游自带的界面文案（见「行为约束」）。
- 不翻译第三方插件的界面文案，只覆盖随本应用分发的插件。
- 不新增语言选择器替代 fnOS 的语言设置：应用包语言跟随 fnOS，DSH 插件语言在 DSH 设置中选择或被同步。
- 不为文档站、README 或构建脚本做多语言版本。
- 不改变应用包的目录结构与打包流程（`i18n/` 是平台约定的新增目录）。

## 验收条件与完成状态

### FNOS-045-01

- `FNOS-045-01-AC-01`：`manifest` 的 `display_name`、`desc`、`changelog` 使用本地化占位符，不再硬编码单一语言。
- `FNOS-045-01-AC-02`：九种语言的键集合一致；缺任一文件或任一键即判定不通过。
- `FNOS-045-01-AC-03`：构建出的 FPK 内包含 `i18n/` 目录及各语言文件。

### FNOS-045-02

- `FNOS-045-02-AC-01`：桌面入口的 `title` 与 `desc` 使用本地化占位符。
- `FNOS-045-02-AC-02`：产品名在各语言中保持 `DeepSeek Harness`。

### FNOS-045-03

- `FNOS-045-03-AC-01`：四个向导文件中所有用户可见文本（`stepTitle`、`label`、`message`、`helpText`、选项 `label`）都使用本地化占位符。
- `FNOS-045-03-AC-02`：字段名、`initValue`、`rules` 中的 `pattern` 不被本地化。
- `FNOS-045-03-AC-03`：每种语言下向导都能正常提交，收集到的字段名与值不变。

### FNOS-045-04

- `FNOS-045-04-AC-01`：六个随包插件注册九种可选语言，语言列表里显示各语言的自称（日本語、한국어、Deutsch、Français、Español、Italiano、Русский）。
- `FNOS-045-04-AC-02`：每种语言的字典键集合与中文完全一致，缺键或多项即判定不通过。
- `FNOS-045-04-AC-03`：切换语言后插件文案立即变化，不需要刷新页面。
- `FNOS-045-04-AC-04`：技术标识（命令、路径、模型 ID、URL、环境变量）在各语言中不被翻译。

### FNOS-045-05

- `FNOS-045-05-AC-01`：fnOS 界面语言为日语时，DSH 界面语言为日语（插件文案为日语，DSH 本体回退英文）。
- `FNOS-045-05-AC-02`：在飞牛中切换界面语言后，DSH 语言随之切换，无需刷新页面。
- `FNOS-045-05-AC-03`：用户在 DSH 里手动切换语言后，该选择在本次运行内保持生效，不会被同步逻辑立刻改回去。
- `FNOS-045-05-AC-04`：fnOS 语言在支持列表之外时，DSH 回退英文而不是报错或空白。
